# Uniक Drippy Apparels

A modern, premium clothing brand website inspired by the style of top streetwear brands.
Built with React, Vite, Tailwind CSS, and Framer Motion.

## Features
- Mobile-first responsive design
- Premium dark/light UI with glassmorphism
- Smooth animations and scrolling
- Product and customized apparel showcase
- WhatsApp and Instagram integration

## Deployment to Vercel

1. Create a [Vercel](https://vercel.com/) account and connect your GitHub.
2. Click "Add New Project" and select the `unika-drippy-apparels` repository.
3. Vercel will automatically detect Vite. 
   - Framework Preset: `Vite`
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Click **Deploy**. Your site will be live in minutes.

## Local Development (Requires Node.js)
```bash
npm install
npm run dev
```
